## 1. 何のためのアプリか

大学の講義ノートと試験勉強に使う、自分専用の手書きノート。（美織）

市販のノートアプリは、全部の機能を使うには課金がほぼ必須になっている。特に困っているのは、ノートの冊数の上限と、PDF取り込みが有料なこと。課金なしで全部使える、自分だけのノートが欲しい。（美織）

書いた内容を伊吹さんと共有して、進捗の管理、試験対策、論文の要約に使いたい。（美織）

## 2. ゴール

- iPadとApple Pencilで、PDFに書き込める（講義ではスライドやPDFへの書き込みが中心）（美織）
- 白紙のノートも作れる（美織）
- ノートの冊数に上限がない（美織）
- PCでも同じノートを開いて、テキストの入力や画像の貼り付けができる。HADの結果やネットで調べた補足をノートにまとめたい（美織）
- 授業の進度、復習、資格勉強の進み具合を記録できる（美織）
- ノートと進捗を伊吹さんに渡せる（美織）
- お金がかからない（美織）

## 3. やらないこと

- アプリにAIを組み込むこと。API利用料がかかるため。要約や問題づくりは、ノートを書き出してチャットで伊吹さんに渡す（伊吹の案）
- 予定やリマインドの管理。計画は伊吹さんが担当し、アプリは記録だけする（美織が伊吹さんに任せると決定）
- 同じノートをiPadとPCで同時に編集したときの「合体」。後から保存したほうを残す（伊吹の案）
- 手書き文字の検索（話に出ていないため。必要になったら追加）（伊吹の案）

## 4. 失敗とみなす状態

- 書き心地が悪くて、結局市販のアプリに戻る
- 講義中にノートが消える、または保存できない
- 進捗の記録が面倒で続かない。前に作ったタスク管理アプリはほぼ運用できなかった（美織）。記録はタップ1回で済むようにする

## 5. 前提と制約

- Macは持っていない。そのためネイティブアプリではなくWebアプリにする（美織）
- 保存先は大学のOneDrive。Googleドライブは写真で容量がいっぱい（美織）
- OneDriveの容量：1TB（使用済み0.2GB）（美織が確認）
- 大学のアカウントは卒業すると使えなくなる。卒業前にデータを移す必要がある
- 教室のWi-Fiが不安定でも書けるようにする。端末に先に保存して、つながったらOneDriveに送る（伊吹の案）

## 6. 作り方の候補と選んだもの

**案1：OneDriveと自動で同期する**
Microsoftアカウントでログインし、保存のたびにOneDriveへ送る。手間はかからない。ただし、大学のアカウントは外部アプリからのログインを止めている場合がある。

**案2：ファイルで受け渡す**
保存するたびにiPadの「ファイル」アプリでOneDriveのフォルダを選ぶ。大学の設定に関係なく確実に動くが、毎回ひと手間かかる。

**予備：個人のMicrosoftアカウントのOneDrive**
無料の容量が5GBしかないため、予備として扱う。

**選んだもの：** 案1を目指す。ただし最初に「大学のアカウントでログインできるか」だけを確かめる小さな試作を作り、止められていたら案2に切り替える。（美織が承認）

**追記（2026-11-24）：** 案1には、アプリをMicrosoft Entra IDのテナントに登録する手続きが必要。登録先は「大学のテナント」か「Azureの無料アカウント」になる。美織が確認したところ、大学のテナントではアプリを登録する権限がなかった。別の場所で登録しても、大学のアカウントでの利用許可が止められている可能性が高いため、案1はやめる。

**決定（美織が承認）：案2の改良版**
- iPad：普段はiPadの中に自動保存。PCで続きをやるときだけ「OneDriveに書き出す」で、ノートブック1冊分を1つのファイルにまとめてOneDriveに保存する。iPadに戻るときは「OneDriveから読み込む」で取り込む
- PC：OneDriveはPCの中のフォルダとして同期されている。EdgeかChromeでは、アプリがそのフォルダに直接読み書きできるため、最初に一度フォルダを選べば以後は自動で保存される

## 6-2. 作業の分け方（美織が承認）

1. 書く部分：白紙とPDFへの手書き、本棚、iPad内への保存。これだけで講義に使える
2. 同期の部分：案2の改良版（ファイルでの受け渡しと、PCでのフォルダ自動保存）
3. 残りの部分：PCでのテキストと画像、進捗、赤シート

実際のコード作成は、美織のPCのClaude Codeで行う（この作業環境は部品をダウンロードできないため）。

## 7. 機能（最初の版）

### ノートの種類
- PDFノート：PDFを取り込み、その上に書き込む。途中に白紙のページを足せる（伊吹の案）
- 白紙ノート：中身のないページだけのノート。見た目は無地・罫線・方眼から選ぶ（伊吹の案）

### 本棚（ノートの整理）
- ノートブック1冊が、講義1科目か資格1つ（伊吹の案）
- 講義なら「第1回」「第2回」、資格なら「第1章」「第2章」と、まとまりを並べる（伊吹の案）
- ノートブックごとに色を付ける

### iPadで書く
- ペン：色と太さを選べる。筆圧で線の太さが変わる（美織のApple PencilはProで、筆圧に対応）
- Apple Pencil Proの「スクイーズ（握る操作）」や「バレルロール（ペンを回す操作）」は、Webアプリからは使えない。ネイティブアプリだけの機能
- 蛍光ペン：文字の下に透けて表示される
- 消しゴム：なぞった線を丸ごと消す
- 元に戻す・やり直す
- Apple Pencilで書いているときは、手のひらが画面に触れても反応しない。指の操作はスクロールと拡大に使う（伊吹の案）

### PCで書く
- ページの好きな位置にテキストボックスを置いて、文字を打ち込める（美織）
- 画像を貼り付けられる。HADの結果はスクリーンショットを貼るのが基本（美織の要望、方法は伊吹の案）
- iPadでも、テキストと画像を見たり動かしたりできる

### 進捗の記録
- まとまりごとに「受講した／読んだ」「復習1回目」「復習2回目」のチェックを付けられる。タップ1回で付き、日付は自動で記録される（伊吹の案）
- ノートブックごとの一覧で、どこまで進んで、どこまで復習したかが分かる

### 赤シート（暗記用）
- 赤シート機能を入れる（美織）
- 隠し方は2種類（伊吹の案）
  - 暗記ペン：オレンジ色の専用ペンで書いた文字が、赤シートをオンにすると見えなくなる
  - 暗記マーカー：緑色の専用マーカーで塗った部分が、赤シートをオンにすると塗りつぶされて隠れる。PDFの元の文字も隠せる
- 赤シートがオンのとき、隠れた部分をタップするとそこだけ見える。もう一度タップで隠れる（伊吹の案）

### 伊吹さんへの受け渡し
- 「進捗を書き出す」ボタン：押すと進捗の文章がコピーされる。チャットに貼れば伊吹さんが計画を立てる（伊吹の案）
- 「PDFで書き出す」ボタン：書き込みを含めたPDFを作る。チャットに添付して、要約や問題づくりに使う（伊吹の案）
- PCのClaudeデスクトップアプリでOneDriveのノートフォルダを接続すれば、伊吹さんが直接読める

### 保存
- 書くたびに自動で端末に保存する。OneDriveには数秒おきにまとめて送る（伊吹の案）
- OneDriveで上書きされる前の版を1つ残し、戻せるようにする（伊吹の案）

## 9. デザイン

### 方向性
主役はノートのページそのもの。画面の飾りは控えめにして、講義中にペンを動かす邪魔をしない。唯一の目立つ要素は「本棚」の画面で、ノートブックをバインダーの背表紙のように並べ、科目ごとの色で見分ける。

### 色
| 名前 | 色 | 使い道 |
|---|---|---|
| 紙 | #F7F8FA | ページと画面の背景。クリーム色ではなく、少し青みのある白 |
| 墨 | #1F2330 | 文字と基本のペン色 |
| 罫線 | #8FA7C9 | 罫線、方眼、区切り線 |
| 机 | #E3E7EE | ページの外側、道具バーの背景 |
| 赤ペン | #C8334A | 復習済みのチェック、注意 |
| 蛍光 | #F2D35B | 蛍光ペンの基本色、選択中の表示 |

### 文字
- BIZ UDPゴシック 1種類。読みやすさを重視して作られた書体で、講義ノートの用途に合う。オフラインでも表示できるよう、アプリに同梱する

### 画面の配置（iPad横向き）

```
┌──┬───────────────────────────────┐
│背│ [ペン][蛍光][消][元に戻す]   ← 道具バー（上に細く）
│表│ ┌─────────────────────────┐ │
│紙│ │                         │ │
│の│ │       PDFのページ        │ │
│列│ │                         │ │
│  │ └─────────────────────────┘ │
└──┴───────────────────────────────┘
```

本棚の画面

```
┌──────────────────────────────────────┐
│ 本棚                        [＋ 新しいノート] │
│ ┃臨┃┃発┃┃心┃┃〇┃                       │
│ ┃床┃┃達┃┃理┃┃〇┃  ← 色付きの背表紙を左寄せで並べる │
│ ┃心┃┃心┃┃統┃┃検┃                       │
│ ┃理┃┃理┃┃計┃┃定┃                       │
└──────────────────────────────────────┘
```

進捗の一覧（講義回は順番そのものなので、番号を付ける）

```
臨床心理学概論
  第1回  ✓受講  ✓復習1  ✓復習2
  第2回  ✓受講  ✓復習1  ・
  第3回  ✓受講  ・      ・
```

### 原則
- 文字は左寄せ
- 角の丸みは、ボタンは小さめ、ページは丸めない。全部に同じ丸みは付けない
- 動きは、操作に反応するものだけにする（ノートを開く、チェックを付ける）
- ボタンの言葉は、何が起きるかをそのまま書く（「PDFで書き出す」「進捗をコピー」）

## 10. 技術（伊吹の案）

- 置き場所：GitHub Pages（無料）。美織のGitHubアカウントを使う
- ホーム画面に追加して使う形式（PWA）。オフラインでも動く
- PDFの表示：PDF.js（Mozilla製、無料）
- 手書きの線：Pointer Events（ブラウザの標準機能）でペンの動きを取り、perfect-freehand（無料）で線をなめらかにする
- PDFの書き出し：pdf-lib（無料）
- OneDriveとの受け渡し：iPadはファイルの書き出し・読み込み。PCはFile System Access API（EdgeとChromeで使える、フォルダに直接読み書きする仕組み）
- 端末への保存：IndexedDB（ブラウザの中のデータ置き場）
